# FireX Flame UI frontend

The Flame UI visualizes FireX task data produced by the Flame server. Its
source, tests, and packaged assets are now owned by the root
[`firexapp`](https://github.com/FireXStuff/firexapp) project.

[Learn more about FireX here.](http://www.firexstuff.com/firexapp/index.html)

## Project setup
```
cd firex_flame_ui_frontend
npm ci
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```

### Run end-to-end tests
```
npm run test:e2e
```

### Run unit tests
```
npm run test:unit
```
