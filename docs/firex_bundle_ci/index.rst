FireX Bundle CI
===============

The ``firex_bundle_ci`` namespace provides FireX tasks that run unit and
integration tests, collect xUnit results, and aggregate coverage. It is owned
and distributed by ``firexapp``; there is no separate build or install step.

The ``firex-bundle-ci`` FireX bundle entry point preserves automatic task
discovery and the existing task names used by FireXApp, Keeper, and Flame CI.
